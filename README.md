## SSH 登录：新手最容易卡住的两个点

卡住的人基本都栽在两处：端口不是 22，root 密码不知道去哪拿。

搬瓦工每台 VPS 的 SSH 端口都是随机生成的，在 KiwiVM 主页面 Main Controls 区域、IP Address 下方就能看到。连接命令格式如下：


ssh root@你的IP地址 -p 端口号


root 密码在左侧菜单 Root password modification 里获取：先把 VPS 关机，再点生成新密码。新密码只显示一次，出来就立刻复制保存。

工具随意：Windows 上 Termius、Xshell、PuTTY 都行，Mac 用自带终端就够了。本地死活连不上——比如 IP 被封——可以用 KiwiVM 里的 Root shell - interactive，在浏览器里通过 VNC 直接操作，应急救援很好用。

连上之后建议做两件事：把 root 密码换成强密码；在面板里开启两步验证，搬瓦工支持 Google Authenticator，最近还加入了 Passkeys 和 Security Keys。重装系统时建议选 Debian 11/12 或 Ubuntu 22.04 LTS，CentOS 7 已停止维护；搬瓦工不提供 Windows 镜像。建站的话，宝塔面板或 LNMP 一键包都能把环境部署简化到几条命令。

## 常见问题

**IP 被封了怎么办？**
先在 KiwiVM 的 Block List Check 里确认是否真的被封。确认后可以付费换 IP，8 美元一次；SLA 套餐每两周免费换一次。着急处理事情，先用 VNC（Root shell - interactive）顶上。

**重装系统数据会丢吗？**
会，重装等于清空磁盘。重装前先建快照。搬瓦工提供免费自动备份，大约每 6 天一次，在 Backups 里查看；手动快照 30 天后自动删除，最多可设 2 个粘性快照长期保留。官方也说明免费备份不作唯一备份方案承诺，重要数据建议自己再存一份。

**能解锁 Netflix 吗？**
不保证。能否解锁取决于分到的 IP，随机性很大，官方没有承诺。

**支持 Windows 吗？**
不支持，镜像全是 Linux：Debian、Ubuntu、CentOS、Fedora 等，32 位和 64 位都有。
